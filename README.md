# Clasificador_MLP_RNA_digitos_manuscritos
Este repositorio contiene una implementación completa de una red neuronal densa (Perceptrón Multicapa / MLP) desarrollada con TensorFlow/Keras para la clasificación de dígitos escritos a mano utilizando el conjunto de datos load_digits de Scikit-Learn.Puntos clave del proyecto:
- Flujo completo de ML: Limpieza, escalado de características (X/16) y división estratificada de datos en conjuntos de entrenamiento, validación y test.
- Arquitectura: Red neuronal feedforward con capas ocultas ReLU y capa de salida Softmax.
- Evaluación: Análisis exhaustivo del rendimiento mediante curva de pérdida/precisión y matriz de confusión, alcanzando una precisión del 97.22% en el conjunto de prueba.
